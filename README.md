# คุยกัน (Kuikan)

แอปห้องคุยด้วยเสียง เปิดห้อง ส่งลิงก์ชวนเพื่อน แล้วคุยกันได้ทันที ไม่ต้องสมัครสมาชิก

- **ล็อบบี้**: ดูห้องที่กำลังคุยกันอยู่ (รีเฟรชเองทุก 8 วินาที) และเปิดห้องใหม่ได้ โดยตั้งชื่อห้อง หัวข้อ อีโมจิ และสีห้อง
- **ห้องเสียง**: รองรับห้องละไม่เกิน 12 คน กดเปิดหรือปิดไมค์เองได้ มีวงไฟกระพริบรอบคนที่กำลังพูด และไอคอนบอกว่าใครปิดไมค์อยู่
- **อีโมจิ**: กดส่งได้ อีโมจิจะลอยขึ้นจากรูปของคนส่ง
- **แชทในห้อง**: มีตัวเลขบอกข้อความที่ยังไม่ได้อ่าน
- **ชวนเพื่อน**: บนมือถือจะเปิดหน้าแชร์ ส่วนบนคอมจะคัดลอกลิงก์ให้ คนที่เปิดลิงก์แค่ตั้งชื่อเล่นก็เข้าห้องได้เลย

## เทคโนโลยี

- **Next.js 16 + Tailwind 4** สำหรับหน้าเว็บและ API
- **[LiveKit](https://livekit.io)** สำหรับเสียงแบบเรียลไทม์ (WebRTC) และใช้ส่งแชทกับอีโมจิด้วย
- ไม่ต้องมีฐานข้อมูล: รายชื่อห้องและจำนวนคนดึงจาก LiveKit โดยตรง ห้องที่ไม่มีคนจะปิดเองภายในประมาณ 1–2 นาที
- ชื่อเล่นกับรูปเก็บไว้ในเบราว์เซอร์ของแต่ละคน (localStorage)

```
src/
  app/api/rooms     GET รายชื่อห้อง / POST เปิดห้อง
  app/api/token     POST ขอสิทธิ์เข้าห้อง (LiveKit token)
  app/room/[id]     หน้าห้อง
  components/       ล็อบบี้ ฟอร์มโปรไฟล์ หน้าห้อง ที่นั่ง แชท
  lib/room-meta.ts  ตรวจข้อมูลห้องและชื่อเล่น (มีเทสต์)
  lib/livekit.ts    เชื่อมต่อ LiveKit ฝั่งเซิร์ฟเวอร์
```

## เริ่มใช้งาน

1. สมัคร [LiveKit Cloud](https://cloud.livekit.io) (มีแพ็กเกจฟรี) แล้วสร้างโปรเจกต์
2. ไปที่ **Settings → API Keys** สร้างคีย์ แล้วคัดลอก URL, API Key และ API Secret
3. ตั้งค่าในเครื่อง:

   ```bash
   cp .env.example .env.local   # แล้วใส่ค่าทั้ง 3 ตัว
   npm install
   npm run dev                  # เปิด http://localhost:3000
   ```

   ถ้าอยากทดสอบโดยไม่ใช้ Cloud ให้รัน `livekit-server --dev` แล้วตั้งค่าเป็น
   `LIVEKIT_URL=ws://127.0.0.1:7880`, `LIVEKIT_API_KEY=devkey`, `LIVEKIT_API_SECRET=secret`

## นำขึ้นออนไลน์ (Vercel)

1. Import repo นี้เข้า Vercel
2. ใส่ Environment Variables `LIVEKIT_URL`, `LIVEKIT_API_KEY` และ `LIVEKIT_API_SECRET`
3. กด Deploy ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ WebSocket เพิ่ม เพราะ LiveKit ดูแลส่วนเรียลไทม์ทั้งหมด

ไมค์บนมือถือใช้ได้เฉพาะเว็บที่เป็น **https** เท่านั้น (Vercel เป็น https ให้อยู่แล้ว)

- มินิเกมในห้อง
- ห่อเป็นแอปมือถือด้วย Capacitor
